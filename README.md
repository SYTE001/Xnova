## 🚀 Local Development

### Installation

```bash
# Clone repository
git clone https://github.com/SYTE001/Xnova.git

# Enter project directory
cd Xnova

# Install dependencies
npm install

# Start Vite local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
